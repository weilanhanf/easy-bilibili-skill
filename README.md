## 📖 项目简介

本项目是一个完整的 B站个人收藏检索解决方案，包含：

- **核心 Skill**：`.agent/skills/easy-bilibili` - 智能收藏检索助手
- **同步脚本**：`scripts/` - Cookie 验证、数据同步工具
- **知识库**：`knowledge/` - 视频文档的结构化存储（同步后自动生成）
- **最佳实践**：触发条件验证、分层索引、精准检索

### 核心特性

| 特性 | 说明 |
|------|------|
| 🎯 精准触发 | 必须包含"B站/哔哩哔哩/bilibili"关键词才执行，避免误触发 |
| 📑 分层索引 | 通过 `data_structure.md` 晿能导航收藏夹 |
| 🔍 组合检索 | 支持多关键词组合搜索，正则精准匹配 |
| 📊 观看状态 | 支持筛选未看/已看/部分观看的视频 |
| 👥 关注管理 | 同步关注的UP主信息 |
| 💬 字幕问答 | 基于视频字幕内容进行问答和总结（需UP主上传字幕） |
| 🔄 灵活同步 | 支持手动和自动两种同步方式 |

### 技术方案说明

本项目采用 **RAG Skill** 方式实现，而非传统的 Embedding + 向量库架构。原因如下：

| 对比项 | RAG Skill（本项目） | 传统向量库 |
|--------|---------------------|-----------|
| 实现复杂度 | 简单，纯文本检索 | 复杂，需要 Embedding 模型 |
| 依赖 | 无外部依赖 | 依赖 Embedding API 或本地模型 |
| 响应速度 | 快，毫秒级 | 较慢，需计算向量相似度 |
| 适用场景 | 数据变动不频繁 | 数据频繁变动、需要语义搜索 |
| 准确性 | 精确匹配 | 语义相关但可能不精确 |

**为什么选择 RAG Skill？**

- 收藏数据短期内变动不大，无需实时更新向量索引
- 充分利用大语言模型的文本理解能力进行检索
- 无需部署额外的向量数据库或调用 Embedding API
- 更轻量、更快速、更易维护

## 🚀 快速开始

> ⚠️ **重要**：首次使用必须完成以下配置，否则无法检索到任何数据！

### 第一步：配置 Cookie

B站收藏数据需要登录才能访问。

**方式一：自然语言触发（推荐）**

直接向 Skill 提问：

```
帮我配置B站登录Cookie
```

Skill 会引导你完成 Cookie 配置。

**方式二：脚本执行**

```bash
python scripts/login.py
```

脚本会显示获取 Cookie 的详细步骤：

1. 登录 [bilibili.com](https://www.bilibili.com)
2. 按 `F12` → Network → 刷新页面
3. 点击任意请求 → Headers → 复制 Cookie 整行
4. 粘贴到脚本中

脚本会自动验证 Cookie 有效性并保存到 `config.json`。

**Cookie 有效期**：约 30 天，过期后重新配置即可。

### 第二步：验证登录

**方式一：自然语言触发**

```
验证我的B站登录状态
```

**方式二：脚本执行**

```bash
python scripts/login.py --check
```

**期望输出**：
```
=== B站登录验证 ===

Cookie 格式检查：
  [OK] 必需字段完整

正在验证 Cookie...

[OK] Cookie 有效
用户ID: 123456789
用户名: 你的用户名

[OK] 配置已更新
```

### 第三步：同步数据

**方式一：自然语言触发（推荐）**

```
同步我的B站收藏
```

Skill 会自动执行同步脚本。

**方式二：脚本执行**

```bash
python scripts/sync.py
```

首次同步会将收藏夹和关注列表下载到本地，根据收藏数量可能需要几分钟到半小时。

#### 同步方式

| 方式 | 命令 | 说明 |
|------|------|------|
| 手动同步 | `python scripts/sync.py` | 用户主动执行，适合收藏变动后更新 |
| 自动同步 | 在 Skill 中说"同步我的B站收藏" | 通过自然语言触发，自动执行同步脚本 |

#### 同步逻辑说明

- **全量覆盖**：每次同步会获取当前所有收藏视频，并生成/覆盖对应的文档文件
- **增量保留**：已存在的视频文档会被更新，不会重复创建
- **取消收藏**：如果取消收藏了某个视频，文档不会自动删除，可说"重置B站知识库"后重新同步

> 💡 推荐同步频率：每周一次或收藏有较大变动时同步。

## 🎯 核心设计理念

### 精准触发条件

**避免误触发**：只有明确包含以下关键词才执行：

| 触发方式 | 示例 |
|----------|------|
| 斜杠命令 | `/easy-bilibili` |
| B站关键词 | `B站搜索xxx`、`我的B站收藏xxx` |
| 哔哩哔哩关键词 | `哔哩哔哩收藏的xxx` |
| bilibili关键词 | `bilibili搜索xxx` |

**不触发的情况**：
- ❌ "西安美食有哪些"（缺少 B站 关键词）
- ❌ "面试视频推荐"（未指定来源）

### 组合关键词检索

**核心原则**：使用组合正则精准匹配，而非单一宽泛关键词

| 用户问题 | 检索策略 | 说明 |
|----------|----------|------|
| B站收藏的西安美食 | `西安.*美食 \| 美食.*西安` | 主题交叉，精准匹配 |
| B站收藏的Java教程 | `Java.*教程 \| 教程.*Java` | 技术主题限定 |
| B站收藏的乒乓球教学 | `乒乓球.*教学` | 运动+限定词 |

### 执行步骤透明

每次执行前先输出执行计划：

```
========================================
📋 执行计划
========================================
1. [验证] 检查触发条件是否满足
2. [导航] 读取索引了解结构
3. [检索] 精准搜索视频文档
4. [输出] 结构化展示结果
========================================
```

## 📊 性能指标

基于示例知识库（10个视频 + 4位UP主）的测试数据：

| 指标 | 数值 | 说明 |
|------|------|------|
| **文件数量** | 14个 | 10个视频文档 + 4个UP主文档 |
| **数据量** | ~35KB | Markdown文档总大小 |
| **平均检索时间** | <100ms | 单次关键词检索耗时 |
| **Token消耗** | ~2000-5000 | 单次检索约消耗（含上下文） |
| **检索准确率** | >95% | 正确关键词组合的命中准确率 |

### Token 消耗分析

| 操作类型 | Token消耗 | 说明 |
|----------|-----------|------|
| 简单检索 | ~2000 | 单关键词搜索，如"Python" |
| 组合检索 | ~3000 | 多关键词搜索，如"美食 视频" |
| 内容问答 | ~4000-6000 | 基于字幕的问答需要读取更多上下文 |
| 全量统计 | ~5000 | 统计所有收藏数据 |

### 提高检索准确率

| 方法 | 说明 | 示例 |
|------|------|------|
| **组合关键词** | 使用2-3个关键词精准定位 | `B站搜索 Python 入门` 优于 `B站搜索 Python` |
| **限定收藏夹** | 指定收藏夹缩小范围 | `编程学习收藏夹的Python视频` |
| **添加状态筛选** | 结合观看状态过滤 | `B站收藏未看的Python教程` |
| **避免宽泛词** | 不使用过于宽泛的词汇 | 避免仅用"教程"、"视频"等 |
| **使用具体名词** | 用具体名称替代泛指 | `B站搜索 成都火锅` 优于 `B站搜索 火锅` |

> 💡 准确率与关键词质量强相关，推荐使用**具体+限定词**的组合方式。

## 🔧 故障排查

### 常见问题速查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| HTTP 412 错误 | API 调用频繁触发反爬 | 等待 30 分钟后重试，或使用自然语言触发（Skill 会自动控制频率） |
| Cookie 无效 | Cookie 已过期（约30天） | 说"更新B站登录Cookie"或运行 `python scripts/login.py` |
| 无数据/空结果 | 首次使用未同步 | 说"同步我的B站收藏"或运行 `python scripts/sync.py` |
| 搜索结果太多 | 关键词过于宽泛 | 使用组合关键词，如"Java 教程"而非仅"Java" |
| 搜索结果不准 | 单一关键词匹配 | 组合 2-3 个关键词精准定位 |
| 字幕问答无结果 | 视频无字幕 | 仅约 60-70% 视频有字幕，可尝试其他关键词 |

### Cookie 相关问题

**问题：Cookie 总是失效**

可能原因：
- 账号在其他设备登录
- 修改了密码
- 浏览器清理了 Cookie

解决方案：
1. 重新登录 bilibili.com
2. 获取新 Cookie 后说"更新B站登录Cookie"

**问题：不知道 Cookie 是否有效**

验证方式：
- 自然语言：说"验证我的B站登录状态"
- 脚本：运行 `python scripts/login.py --check`

### 同步相关问题

**问题：同步中断或失败**

常见原因：
- 网络连接超时
- API 触发反爬（HTTP 412）
- Cookie 过期

解决方案：
1. 检查网络连接
2. 等待 30 分钟后重新同步
3. 验证 Cookie 有效性

**问题：同步速度慢**

正常现象，取决于：
- 收藏视频数量
- 网络速度
- B站 API 响应

建议：首次同步后，日常增量同步很快。

### 检索相关问题

**问题：找不到已收藏的视频**

排查步骤：
1. 确认已完成数据同步
2. 尝试更精确的关键词
3. 检查视频是否在特定收藏夹
4. 说"查看我的B站收藏夹列表"确认分类

**问题：视频内容问答不准确**

可能原因：
- 视频无字幕（约 30-40% 视频无字幕）
- 关键词与字幕表述不一致
- 视频内容本身不包含相关信息

解决方案：
1. 尝试同义词或相关概念
2. 直接观看视频确认内容
