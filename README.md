## 📖 项目简介

本项目是一个完整的 B站个人收藏检索解决方案，包含：

- **核心 Skill**：`.agent/skills/easy-bilibili` - 智能收藏检索助手
- **同步脚本**：`scripts/` - Cookie 验证、数据同步工具
- **知识库**：`knowledge/` - 1400+ 视频文档的结构化存储
- **最佳实践**：触发条件验证、分层索引、精准检索

### 核心特性

| 特性 | 说明 |
|------|------|
| 🎯 精准触发 | 必须包含"B站/哔哩哔哩/bilibili"关键词才执行，避免误触发 |
| 📑 分层索引 | 通过 `data_structure.md` 智能导航收藏夹 |
| 🔍 组合检索 | 支持多关键词组合搜索，正则精准匹配 |
| 📊 观看状态 | 支持筛选未看/已看/部分观看的视频 |
| 👥 关注管理 | 同步关注的UP主信息 |
| 🔤 字幕检索 | 支持视频字幕内容搜索（需UP主上传字幕，约60-70%覆盖率） |

## 🚀 快速开始

> ⚠️ **重要**：首次使用必须按顺序完成以下三步，否则无法检索到任何数据！

### 第一步：配置 Cookie

B站收藏数据需要登录才能访问。提供两种登录方式：

#### 方式一：扫码登录（推荐，最简单）

```bash
python scripts/login.py
```

运行后会显示二维码，用 **B站 App** 扫码即可自动完成登录。无需手动复制任何内容！

> 如果终端不支持显示二维码，脚本会自动打开浏览器，用手机扫码即可。

#### 方式二：手动输入 Cookie

如果扫码登录失败，可以手动输入：

```bash
python scripts/login.py --cookie
```

按提示从浏览器复制完整 Cookie：

1. 登录 [bilibili.com](https://www.bilibili.com)
2. 按 `F12` → Network → 刷新页面
3. 点击任意请求 → Headers → 复制 Cookie 整行
4. 粘贴到脚本中

**Cookie 有效期**：约 30 天，过期后重新运行 `login.py` 即可。

### 第二步：验证登录

```bash
python scripts/login.py --check
```

**期望输出**：
```
=== B站登录验证 ===

Cookie 格式检查：
  [OK] 必需字段完整

正在验证 Cookie...

[OK] Cookie 有效
用户ID: 123456789
用户名: 你的用户名

[OK] 配置已更新
```

### 第三步：同步数据

```bash
# 完整同步（首次推荐）
python scripts/sync.py
```

首次同步会将收藏夹和关注列表下载到本地，根据收藏数量可能需要几分钟到半小时。

## 🎯 核心设计理念

### 精准触发条件

**避免误触发**：只有明确包含以下关键词才执行：

| 触发方式 | 示例 |
|----------|------|
| 斜杠命令 | `/easy-bilibili` |
| B站关键词 | `B站搜索xxx`、`我的B站收藏xxx` |
| 哔哩哔哩关键词 | `哔哩哔哩收藏的xxx` |
| bilibili关键词 | `bilibili搜索xxx` |

**不触发的情况**：
- ❌ "西安美食有哪些"（缺少 B站 关键词）
- ❌ "面试视频推荐"（未指定来源）

### 组合关键词检索

**核心原则**：使用组合正则精准匹配，而非单一宽泛关键词

| 用户问题 | 检索策略 | 说明 |
|----------|----------|------|
| B站收藏的西安美食 | `西安.*美食 \| 美食.*西安` | 主题交叉，精准匹配 |
| B站收藏的Java教程 | `Java.*教程 \| 教程.*Java` | 技术主题限定 |
| B站收藏的乒乓球教学 | `乒乓球.*教学` | 运动+限定词 |

### 执行步骤透明

每次执行前先输出执行计划：

```
========================================
📋 执行计划
========================================
1. [验证] 检查触发条件是否满足
2. [导航] 读取索引了解结构
3. [检索] 精准搜索视频文档
4. [输出] 结构化展示结果
========================================
```

## 🔮 后续优化方向

### 1. 向量检索（语义搜索）

当前使用关键词搜索，后续可引入向量检索实现语义搜索：

| 对比 | 关键词搜索（当前） | 向量检索（优化后） |
|------|-------------------|-------------------|
| 搜索方式 | 精确匹配关键词 | 语义相似度匹配 |
| 示例 | 搜索"味道"只能匹配"味道" | 搜索"味道"能匹配"口感"、"风味" |
| 依赖 | 无 | Embedding模型 |
| 存储 | Markdown文件 | ChromaDB/本地向量库 |

### 2. ASR 音频转写（无字幕视频兜底）

当前只能获取有字幕的视频（约 60-70% 覆盖率），后续可引入 ASR 实现 100% 覆盖：

| 方案 | 覆盖率 | 成本 | 说明 |
|------|--------|------|------|
| B站字幕API（当前） | ~67% | 免费 | 仅获取有字幕的视频 |
| DashScope ASR | 100% | 按时长收费 | 音频上传识别 |
| OpenAI Whisper | 100% | 按时长收费 | 类似 DashScope |

## 🔧 故障排查

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| HTTP 412 | 触发反爬 | 等待 30 分钟后重试 |
| Cookie 无效 | 已过期 | 运行 `login.py` 更新 |
| 无数据 | 未同步 | 运行 `sync.py` 初始化 |
| 结果太多 | 关键词太宽 | 使用更具体关键词 |
| 结果不准 | 单关键词 | 组合多个关键词 |

## ⚠️ 注意事项

- **Cookie 有效期**：约 30 天，过期后重新配置即可
- **同步频率**：按需同步，避免频繁调用触发反爬
- **数据范围**：仅支持检索自己的收藏数据
- **字幕检索**：仅支持UP主已上传字幕的视频
