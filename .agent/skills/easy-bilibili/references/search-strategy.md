# 检索策略参考

## 关键词组合原则

### 主题交叉检索

用户问题包含两个及以上主题时，使用正则表达式组合：

| 用户问题 | 检索表达式 | 说明 |
|----------|-----------|------|
| 西安美食 | `西安.*美食 \| 美食.*西安` | 同时包含两个词 |
| Java面试 | `Java.*面试 \| 面试.*Java` | 技术面试限定 |
| 乒乓球教学 | `乒乓球.*教学 \| 教学.*乒乓球` | 运动教程限定 |

### 单主题检索

用户问题只有一个主题时，直接匹配：

| 用户问题 | 检索表达式 |
|----------|-----------|
| 面试视频 | `面试` |
| React教程 | `React` |
| 口琴 | `口琴` |

当用户明确排除某类内容时：

| 用户问题 | 检索策略 |
|----------|----------|
| 西安美食（不要旅游） | 匹配 `西安.*美食`，排除含 `旅游、攻略、景点` |

## 多轮迭代机制

### 轮次策略

| 轮次 | 策略 | 操作 |
|------|------|------|
| 1 | 精准匹配 | 使用组合正则搜索 |
| 2 | 放宽条件 | 去除限定词，仅用主关键词 |
| 3 | 分类筛选 | 在指定收藏夹内搜索 |

### 终止条件

- 找到足够信息 → 输出结果
- 达到 3 轮无结果 → 明确告知用户
- 结果超过 20 条 → 分页或建议缩小范围

## 性能优化

### grep 搜索优化

```bash
# 指定精准的 path 和 pattern
grep -l "西安.*美食" knowledge/videos/*.md

# 控制输出数量
grep -l "关键词" knowledge/videos/*.md | head -20
```

### Read 读取优化

- 索引文件：`limit=100-300`
- 视频文档：可整文件读取（约 30-50 行）
- 避免全目录扫描（1400+ 文件）
