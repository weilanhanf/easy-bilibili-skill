# 触发条件验证

## 核心原则

**只有明确指定 B站来源时才触发此 Skill**

---

## 触发条件检查清单

### ✅ 必须满足的条件

- [ ] 问题包含 `B站` 或 `哔哩哔哩` 关键词
- [ ] 问题包含 `我的B站` 或 `B站收藏` 指向性短语
- [ ] 使用了斜杠命令 `/easy-bilibili`

### ❌ 不满足条件的情况

- [ ] 仅包含主题关键词，无来源指定
- [ ] 使用通用词汇如"推荐"、"有哪些"
- [ ] 问题未指定数据来源

---

## 判断示例

### 触发 ✅

| 问题 | 触发原因 |
|------|----------|
| `B站搜索西安美食` | 包含"B站搜索"前缀 |
| `我的B站收藏有哪些面试视频` | 包含"我的B站收藏" |
| `哔哩哔哩里收藏的Java教程` | 包含"哔哩哔哩" |
| `/easy-bilibili sync` | 斜杠命令直接调用 |

### 不触发 ❌

| 问题 | 不触发原因 |
|------|-----------|
| `西安美食有哪些` | 缺少 B站 关键词 |
| `推荐一些面试视频` | 未指定来源 |
| `Java教程推荐` | 未指定来源 |
| `乒乓球教学视频` | 未指定来源 |

---

## 友好提示模板

当用户问题不满足触发条件时：

```
您的提问格式可能需要调整。

正确格式示例：
- B站搜索 [关键词]
- 我的B站收藏中关于 [主题] 的视频
- 哔哩哔哩收藏的 [分类] 视频

请使用以上格式重新提问。
```

## 特殊场景

### 初始化请求

| 问题 | 处理方式 |
|------|----------|
| `初始化我的B站收藏` | 执行 `python scripts/sync.py` |
| `同步B站数据` | 执行 `python scripts/sync.py` |

### Cookie 过期

当同步失败提示 Cookie 无效时：

```
Cookie 已过期，请按以下步骤更新：

1. 登录 bilibili.com
2. F12 → Network → 刷新页面
3. 点击请求 → Headers → Cookie
4. 复制整行 Cookie
5. 运行 python scripts/login.py 更新
```
